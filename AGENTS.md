# AGENTS.md

Shared rules for any coding agent working in **memento**.

1. Read `CLAUDE.md` and `maps/home.md` first.
2. This vault is **public** — follow `docs/privacy-public.md` strictly.
3. Place notes using `docs/taxonomy.md`; use `templates/` for new notes.
4. Update the relevant `maps/*.md` when adding a non-trivial evergreen or project note.
5. Nested code projects: see `.meta` and `docs/meta-repos.md` — do not dump large code trees into the vault.
6. Prefer small, reviewable changes. Do not mass-rename historical paths unless the task is explicitly Wave 2 migration.
7. Never commit secrets or force-push without explicit user approval.

Full constitution: `docs/garden-constitution.md`.
